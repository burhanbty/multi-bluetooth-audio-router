# Security policy

## Supported versions

This project is currently experimental. Security fixes are applied to the latest revision on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of opening a public issue. Include reproduction steps, affected versions, and the expected impact. Do not include unrelated local device identifiers or audio diagnostic logs.

The application processes audio locally and does not intentionally make network requests. Any unexpected network activity should be treated as a bug and reported.
